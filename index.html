⚙ PENGATURAN INTEGRASI

Hubungkan API Backend Aman

Masukkan URL backend milik Anda yang mengimplementasikan kontrak endpoint di bawah. Jangan masukkan API key AI atau service-role key Supabase di HTML atau browser. Backend menyimpan semua rahasia, memvalidasi sesi pengguna, menerapkan kuota, dan meneruskan permintaan AI.

Mode SaaS & keamanan

Login, registrasi member, panel admin, kuota, storage privat, pembayaran, dan monitoring biaya harus dilaksanakan oleh backend dengan autentikasi server-side, database dan hak akses. Tidak boleh dibuat palsu melalui localStorage.

Belum terhubung ke akun SaaS.

Kontrak Endpoint (untuk developer backend)

GET /health
GET /me
POST /auth/login dan /auth/logout (cookie HttpOnly)
POST /ai/ideas → {"concepts":[5 items]}
POST /ai/storyboard → {"masterPrompt":"...","scenes":[...]}
POST /ai/scene → {"scene":{...}}
POST /ai/vision (multipart gambar) → {"bible":"..."}
POST /ai/atm (multipart frame/video) → {"analysis":"..."}
POST /ai/suggest → {"ideas":[...]}
POST /ai/style → {"style":"..."}

Semua request memakai credentials: include. Server harus mengizinkan origin situs ini melalui CORS dan memakai perlindungan CSRF yang sesuai. Endpoint hanya dapat diakses bila backend benar-benar dibuat dan di-deploy.

Pengaturan lokal

Ini preferensi perangkat, bukan pengaturan admin server. Admin sungguhan harus dikelola pada backend.
